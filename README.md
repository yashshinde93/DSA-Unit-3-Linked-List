# DSA-Unit-3-Linked-List
# Employee Management System Using Linked List

## Problem Statement
Design and implement an Employee Management System using a
Singly Linked List in C++. Store Employee ID and Name and
display employee records.

## Algorithm
1. Create a node containing Employee ID and Name.
2. Allocate memory dynamically for each node.
3. Insert employee nodes at the end of the linked list.
4. Traverse the linked list using a pointer.
5. Display all employee records.

## Explanation
A Singly Linked List is used to store employee records dynamically.
Each node contains employee ID, name and a pointer to the next node.
Dynamic memory allocation is used to create new nodes.

## Sample Input
101 Rahul
102 Priya
103 Amit

## Sample Output
Employee Records:
ID: 101 Name: Rahul
ID: 102 Name: Priya
ID: 103 Name: Amit
